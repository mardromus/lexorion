# Lexorion landing page

A responsive, no-build static site for Lexorion. The entire landing page and its interactive sample simulation live in `index.html`.

## Publish

Upload this folder to a static hosting provider such as GitHub Pages, Netlify, or Vercel. No package install or build step is required; `index.html` is the site entry point.

## Before launch

- In `index.html`, set `CONFIG.contactEmail` to an inbox your team monitors. The demo request form opens a visitor's email app with a prefilled message; it does not submit or store data itself.
- Confirm the 1,000+ user figure, college-partner wording, and research-publication status. Add named institutions or a paper link only when those details are ready to share.
- The courtroom walkthrough is a static sample, not a connected AI service. Keep the preview note unless the live product is integrated.
